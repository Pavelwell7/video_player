# Видеоплеер

Проект кастомного видеоплеера на HTML, CSS и JavaScript.

![video_player](https://github.com/user-attachments/assets/3f70a18c-a0e0-4338-83b7-e471f1d37559)

## Возможности и структура

- Гибкая вёрстка на Flexbox
- Основные стили лежатат в папке `css` в файле `styles.css`

### Кнопочки

Иконки лежат в папке `css` в  файле `font-awesome.min.css`, шрифты в папке `fonts`:

- Play / Pause
- Включение и выключение звука
- Полноэкранный режим

## Запуск проекта

- Сайт с прототипом видеоплеера можно посмотреть по ссылке [video_player](https://pavelwell7.github.io/video_player/).
- Скопировать репозиторий video_player и открыть файл `index.html` в любом браузере.
